# 复现范围

本仓库区分数值结果核验和重新执行学习流程。

## 归档结果核验

`paper_results/`包含正文图表对应的数值数据。可在不提供任何模型的条件下：

1. 重算均值、样本标准差、联合成功数与终态指标范围。
2. 重画训练双子图、方差演化、五维意见轨迹、敏感性三联图、规模四子图和随机初态三联图。
3. 重新核验100名专家的严格反转数，并按分位数及最小编号规则抽取代表性个体。

意见轨迹仅包含当时保存的状态，不补造中间轨迹，也不追加终止后的HK演化。
方差图的局部平滑仅用于显示，保留原始淡线与HK更新边界；统计仍使用未平滑数据。
训练图按回合结束时的累计步数分组，包含全部成功与失败回合。

## 从头训练与独立评估

仓库给出环境、奖励、PPO设置、种子、初态生成器、训练与评估命令。
审稿人可从头训练本地模型，然后在相同评估初态和终态标准下执行实验。
每个新运行目录记录配置、实际步数、软件版本和checkpoint SHA256。
原实验模型权重不分发，因此不能直接加载原策略重现其逐步动作。

训练随机种子并不保证不同硬件、线程设置、依赖版本与运行中断方式下的逐位相同结果。
重新训练的表现应据实报告，不强制其等于归档表中的成功率或指标。
若新结果不同，应先比较配置、软件版本、随机生成器和训练完成状态。

## 指标定义

- 总方差：各方案维度的总体方差之和，`ddof=0`。
- 重心偏移：初始与终态群体均值向量之差的L2范数除以`sqrt(M)`。
- 训练序数成本：相对于初始偏好，平均每名专家的严格反转数。
- 奖励惩罚：序数成本和重心偏移的正增量；下降不退还之前的罚分。
- 终态OPRR：严格反转对数除以初始有效严格偏好对数，再乘100。
- 初态或终态并列不构成严格反转。所有归档初态的方案取值无并列，
  因而有效偏好对总数等于`N*M*(M-1)/2`。
- 软共识方差水平为`V <= 0.05`，联合成功还要求`G <= 0.45`。

RL环境在每次完整状态转移后检测终止；第N次个体干预的状态转移包含一次HK同步更新。
如果在不足一轮时满足联合条件，立即结束，不额外执行一次HK更新。
自然演化模型的轮次是实际同步更新次数，PPO轮次是干预步数/N，不能作为运行耗时比较。
自然演化的`intervention_steps=0`表示没有外部个体干预，不表示计算成本为0。

## 实验范围

规模实验为各规模分别训练，不是一个策略跨形状迁移。稳定性实验保持初态分布不变，
不属于初始分布OOD。分布OOD结果仅覆盖列出的四种分布，不代表全部可能的分布变化。
发布内容不归档开发过程中全部探索性实验，不应据此宣称所有测试均成功。

## 整理版代码验证

发布环境合并了原主环境与无掩码副本，仅用开关控制动作掩码；未激活的旧奖励兼容项已移除。
实际使用的状态转移、观察顺序、正增量奖励和联合终态条件保留。
发布前通过环境/指标/协议单元测试，并与原环境进行逐步数值对照。
这类检查验证代码整理的等价性，不替代重新进行完整10M训练。
